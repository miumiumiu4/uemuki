# うえむき（見本）

みんなの一歩を見せ合い、スタンプで応援し合う健康アプリ「うえむき」の触れる見本です。
スマホのブラウザで開き、「ホーム画面に追加」するとアプリのように使えます。

- ホーム：仲間の一歩がカードで並ぶ。カードを開くとルートと応援スタンプ
- からだ：筋トレメニュー表（報告で種目が増える）、瞑想、呼吸法
- 歩く：歩いた道を地図に残す（見本は早送りの例のデータ）
- ヒント：歩数がたまるとヒントカードが開く
- マイページ：InBodyの推移グラフ、項目ごとの公開・非公開

見本なので、名前と数字はすべて例です。記録はその端末の中だけに保存されます。
本番アプリでは、スマホの歩数の自動取り込みとGPSに対応します。

ファイルを置くだけで動きます（ビルド不要）。手元で見るときは `python3 -m http.server` で開いてください。
